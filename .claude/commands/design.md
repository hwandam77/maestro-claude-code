# /design - Gemini로 디자인/UI 태스크 라우팅

gemini (gemini-3.1-pro-preview)에 UI/디자인/프론트엔드 태스크를 위임합니다.

## 사용법
```
/design 대시보드 컴포넌트 디자인
/design 로그인 화면 레이아웃
/design CSS 스타일 작성
```

## 실행 방법

다음 bash 명령을 실행하세요:

```bash
cd /Users/hwandam/workspace/maestro-claude-code && ./scripts/maestro-route.sh --type design "$ARGUMENTS"
```

$ARGUMENTS 자리에 사용자가 입력한 태스크 설명을 그대로 넣으세요.
