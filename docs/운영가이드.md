# Maestro Claude Code 운영 가이드

> 최종 업데이트: 2026-03-08

---

## 1. 시스템 개요

6개 모델 체제로 역할별 최적 AI를 라우팅하여 비용 절감과 품질 향상을 동시에 달성합니다.

| 모델 | 접근 방법 | 역할 | 비용 |
|------|-----------|------|------|
| **Claude (opus/sonnet/haiku)** | `claude` CLI | 기본 개발, 설계, 리뷰 | Anthropic 구독 |
| **GLM-5 / GLM-4.5-Air** | `claude-glm` CLI (ZAI API) | Claude 저비용 대체 | ZAI Coding Plan $3/월 |
| **gpt-5.3-codex** | `codex` CLI | 코드 생성, 리뷰, 테스트 | OpenAI 구독 |
| **gemini-3.1-pro-preview** | `gemini` CLI | 디자인, UI, 멀티모달 | Google 구독 |
| **Qwen3.5-122B** | nexus:8080 (llama-server) | 대형 컨텍스트, 로컬 추론 | 자체 서버 (전기료) |
| **Qwen3-Coder-30B-A3B** | cognit:8000 (vLLM) | 코드 특화 로컬 추론 | 자체 서버 (전기료) |

---

## 2. 일상 운영

### 2.1 기본 사용

```bash
# 기본: Anthropic 구독 Claude
claude

# 저비용 대체: ZAI API 경유 GLM-5
claude-glm

# 스크립트 경유 (라우팅 로직 포함)
./scripts/maestro.sh
```

### 2.2 멀티 AI 실행

```bash
# routing.config.yaml 기반 자동 라우팅
/multi-ai-run

# council.config.yaml 기반 다중 AI 리뷰
/multi-ai-review

# 오케스트레이션 (모드 선택)
/orchestrate-standalone --mode=lite       # 경량, 핫픽스용
/orchestrate-standalone --mode=standard   # 일반 개발 (기본값)
/orchestrate-standalone --mode=full       # 배포 전 전체 게이트
```

### 2.3 라우팅 설정

| 파일 | 역할 |
|------|------|
| `routing.config.yaml` | role/task_type/domain 3계층 라우팅 규칙 |
| `council.config.yaml` | 멀티 AI 리뷰 패널 구성 |
| `.env` | API 키, 타임아웃, 엔드포인트 설정 |

## 3. 서버 관리

### 3.1 nexus 서버

| 항목 | 값 |
|------|----|
| 호스트 | `100.64.189.120` (Tailscale) |
| 포트 | `8080` |
| 모델 | Qwen3.5-122B (Q3_K_XL) |
| 서비스 | llama-server |
| GPU | RTX 3090 x3 |
| 컨텍스트 | 400K tokens |

```bash
# 연결 확인
curl http://100.64.189.120:8080/health

# SSH 접속
ssh nexus  # ~/.ssh/config 설정 필요
```

### 3.2 cognit 서버

| 항목 | 값 |
|------|----|
| 호스트 | `100.89.224.48` (Tailscale) |
| 포트 | `8000` |
| 모델 | Qwen3-Coder-30B-A3B-Instruct AWQ-4bit |
| 서비스 | vLLM (systemd) |
| GPU | RTX 3080 Ti x2 (GPU당 11.4GB/12GB 사용) |
| 컨텍스트 | 20K tokens |

```bash
# vLLM 서비스 상태 확인
ssh cognit "systemctl status vllm-qwen3-coder.service"

# 서비스 재시작
ssh cognit "sudo systemctl restart vllm-qwen3-coder.service"

# 연결 확인
curl http://100.89.224.48:8000/health
```

### 3.3 헬스체크

```bash
# 전체 서버 상태 확인
./scripts/health-check.sh
```

> **필수**: 서버 접근에는 Tailscale VPN이 반드시 연결되어 있어야 합니다.

## 4. Hook 프로파일

설정 파일: `.claude/hooks/hook-profiles.yaml`

| 프로파일 | 훅 수 | 용도 | 사용 시점 |
|----------|-------|------|-----------|
| **lite** | 2 | 최소 검증 | 핫픽스, 긴급 배포 |
| **standard** | 6 | 일반 개발 게이트 | 일반 개발 (기본값) |
| **full** | 16 | 전체 품질 게이트 | 프로덕션 배포 전 |

```bash
# 프로파일 전환 예시 (orchestrate-standalone)
/orchestrate-standalone --mode=lite      # lite 훅 프로파일
/orchestrate-standalone --mode=standard  # standard 훅 프로파일
/orchestrate-standalone --mode=full      # full 훅 프로파일
```

## 5. 트러블슈팅

### 서버 접근 불가

```
증상: nexus/cognit 연결 타임아웃
원인: Tailscale VPN 미연결 또는 서버 다운
```

1. Tailscale 상태 확인: `tailscale status`
2. VPN 재연결: `tailscale up`
3. 서버 ping: `ping 100.64.189.120` / `ping 100.89.224.48`
4. **fallback**: 해당 라우팅을 Claude (Anthropic) 로 임시 처리

---

### Qwen3-Coder VRAM 부족

```
증상: cognit vLLM OOM 에러, 요청 거부
원인: 컨텍스트 초과 또는 동시 요청 과부하
```

1. 컨텍스트를 **20K tokens 이하**로 유지
2. 동시 요청 **1개로 제한**
3. 더 큰 모델 필요 시 nexus(Qwen3.5-122B) 또는 Claude로 라우팅
4. Qwen3-Coder-Next-AWQ-8bit (24B)은 VRAM 부족으로 사용 불가 (확인됨)

---

### CLI 인증 만료

```
증상: codex / gemini CLI 인증 오류
원인: 토큰 만료
```

```bash
# Codex 재인증
codex login

# Gemini 재인증
gemini auth login
```

---

### ZAI API 연결 오류

```
증상: claude-glm 실행 시 401/403 에러
원인: 환경변수 미설정 또는 잘못된 키
```

올바른 설정 확인:

```bash
# 반드시 ANTHROPIC_AUTH_TOKEN 사용 (ANTHROPIC_API_KEY 아님)
export ANTHROPIC_BASE_URL=https://api.z.ai/api/anthropic
export ANTHROPIC_AUTH_TOKEN=${ZAI_API_KEY}
```

---

### Wrapper 타임아웃

```
증상: maestro.sh 실행 중 타임아웃 종료
원인: TIMEOUT 설정값 부족
```

`.env` 파일에서 조정:

```bash
TIMEOUT=300  # 기본값 (초 단위), 필요 시 증가
```

## 6. 비용 구조

| 항목 | 비용 | 비고 |
|------|------|------|
| **Claude** | Anthropic 구독 (월정액) | opus/sonnet/haiku 포함 |
| **GLM-5 / GLM-4.5-Air** | ZAI Coding Plan $3/월 | `/api/anthropic` 엔드포인트 필수 |
| **gpt-5.3-codex** | OpenAI 구독 | 코드 특화 |
| **gemini-3.1-pro-preview** | Google 구독 | 멀티모달 특화 |
| **nexus 서버** | 전기료만 | RTX 3090 x3, 자체 운영 |
| **cognit 서버** | 전기료만 | RTX 3080 Ti x2, 자체 운영 |

### 비용 절감 팁

- 일반 작업: `claude-glm` 우선 사용 (Claude 구독 소비 절약)
- 대형 컨텍스트: nexus 서버 활용 (API 비용 0)
- 코드 생성/반복 작업: cognit 서버 활용 (API 비용 0)
- ZAI API는 반드시 Coding Plan 전용 엔드포인트(`/api/anthropic`) 사용 (표준 API는 별도 과금)
