## 3. Warp 환경 생성 🔄 (진행 중)

### 구성 정보

| 항목 | 값 |
|------|-----|
| 환경 이름 | `maestro-claude-code` |
| Docker 이미지 | `warpdotdev/dev-base:1` |
| 저장소 | `hwandam77/maestro-claude-code` (비공개) |

### Setup 명령어 (6개)

```bash
# 1. Claude Code CLI 설치
cd maestro-claude-code && npm install -g @anthropic-ai/claude-code

# 2. claude-code-router 설치
cd maestro-claude-code && npm install -g claude-code-router@2.0.0

# 3. MCP 서버 설치
cd maestro-claude-code && npm install -g @modelcontextprotocol/server-filesystem @modelcontextprotocol/server-git @modelcontextprotocol/server-memory

# 4. Python 패키지 설치
cd maestro-claude-code && pip install playwright context7-mcp tavily-python

# 5. 스크립트 실행 권한 부여
cd maestro-claude-code && chmod +x scripts/*.sh tests/*.sh

# 6. 환경 변수 파일 생성
cd maestro-claude-code && cp .env.example .env
```

### 대기 중인 작업
**GitHub 인증 필요** - 비공개 저장소 접근을 위해 Warp Agent GitHub 앱 설치 필요

#### 인증 단계
1. https://github.com/apps/warp-agent/installations/new 접속
2. `hwandam77` 계정 선택
3. "Only select repositories" 선택
4. `maestro-claude-code` 저장소 선택
5. "Install" 클릭

### 환경 생성 명령어 (인증 완료 후 실행)

```bash
warp environment create \
  --name maestro-claude-code \
  --docker-image warpdotdev/dev-base:1 \
  --repo hwandam77/maestro-claude-code \
  --setup-command "cd maestro-claude-code && npm install -g @anthropic-ai/claude-code" \
  --setup-command "cd maestro-claude-code && npm install -g claude-code-router@2.0.0" \
  --setup-command "cd maestro-claude-code && npm install -g @modelcontextprotocol/server-filesystem @modelcontextprotocol/server-git @modelcontextprotocol/server-memory" \
  --setup-command "cd maestro-claude-code && pip install playwright context7-mcp tavily-python" \
  --setup-command "cd maestro-claude-code && chmod +x scripts/*.sh tests/*.sh" \
  --setup-command "cd maestro-claude-code && cp .env.example .env"
```

## 참고 사항

### Warp 환경 실행 흐름
```
트리거 (Slack/Linear/API)
    ↓
Warp 환경 시작 (클라우드 컨테이너)
    ↓
Docker 이미지 로드 (warpdotdev/dev-base:1)
    ↓
GitHub에서 코드 clone
    ↓
Setup 명령어 자동 실행
    ↓
에이전트 작업 시작
    ↓
결과 반환 후 컨테이너 종료
```

### 로컬 환경과의 차이
- Warp 환경은 **클라우드에서 실행**되며 로컬 Mac에는 영향 없음
- 매 실행마다 **격리된 새 컨테이너**에서 시작
- API 키는 **Warp Secrets**로 별도 관리 필요
